Perguntas frequentes

É grátis mesmo? Qual a pegadinha?

Nenhuma. Sem plano pago, sem ads, sem limite de notas. O projeto vive no GitHub e você baixa direto das Releases.

Precisa de internet?

Não. Tudo é local: notas, busca, configurações. Internet só para baixar e atualizar.

Onde ficam minhas notas?

Em %AppData%\StickyNotes\notes.db (SQLite), com o conteúdo criptografado via DPAPI. Faça backup copiando essa pasta.

Funciona com dois monitores?

Sim. Nas Configurações (⚙ no deck) você escolhe o lado — esquerda ou direita — e em qual monitor o deck fica grudado.

Ele fica por cima de tudo e atrapalha?

As notas ficam sempre visíveis de propósito, mas o deck recolhe para uma pílula de 24px. Um Esc e tudo se recolhe.

Tem como recuperar nota apagada?

Notas excluídas vão embora de verdade (sem lixeira, por enquanto). Para “guardar sem mostrar”, use Arquivar 🗂 em vez de excluir.
